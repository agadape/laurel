## 1. Illia Polosukhin (NEAR) — @ilblackdragon

His example: an attested LLM decides whether a transaction comes from stolen funds. *"Code is law very much literally now."* [x.com/ilblackdragon/status/2104785986307907781](https://x.com/ilblackdragon/status/2104785986307907781), 2026-09-29.
- **Stopping crime without KYC.** *"We have better data and talent to create systems that don't require KYC and actually deter criminals while giving full freedom to real users."* (SHIELD context.) [x.com/ilblackdragon/status/2104710316919869737](https://x.com/ilblackdragon/status/2104710316919869737), 2026-09-28. See also SHIELD stopping $50M+ in Bitget-hack flows: [2104706901837795348](https://x.com/ilblackdragon/status/2104706901837795348), 2026-09-28.

[x.com/ilblackdragon/status/2101165098622648395](https://x.com/ilblackdragon/status/2101165098622648395), 2026-09-19.
- **AI-driven security crisis.** *"We are at Security Armageddon now."* He argues uncensored models are needed for defense, along with formal verification and *"Hosting platforms that can secure the software even from platform itself."* [2113139098265501892](https://x.com/ilblackdragon/status/2113139098265501892), 2026-10-22. NEAR AI launched a Cybersecurity program (uncensored models inside TEEs) on 2026-10-29 [2115898183566114910](https://x.com/ilblackdragon/status/2115898183566114910) and a RED Sandbox on 2026-10-31 [2116404836149481712](https://x.com/ilblackdragon/status/2116404836149481712). He also pitches private formal verification as cheaper than using Anthropic [2113426600628998482](https://x.com/ilblackdragon/status/2113426600628998482), 2026-10-23.
- **Agents that earn money.** *"Don't just do the job - make an agent that will earn money from doing it for others."* (about market.near.ai jobs) [2112350835913163123](https://x.com/ilblackdragon/status/2112350835913163123), 2026-10-20. *"The era of specialized agents is coming. Keep them private and verifiable and open for business."* [2100770332734877862](https://x.com/ilblackdragon/status/2100770332734877862), 2026-09-18.
- **Open calls to build.** On Robinhood Chain assets reaching Intents: *"What are you going to build?"* [2107977499611443281](https://x.com/ilblackdragon/status/2107977499611443281), 2026-10-07. (Ideas list: [2106269343881519444](https://x.com/ilblackdragon/status/2106269343881519444), 2026-10-03; see 04_illia_ideas.md.)

**What would make Illia lean forward**
1. **A verifiable judgement oracle.** A NEAR AI (TEE) model judges something messy, such as "is this deposit tied to a known hack?", "did this freelancer deliver?", or "is this claim true per sources X/Y?". It posts an attested verdict, and a NEAR contract or Intents flow acts on it. This is his "code is law, literally" post made real.
2. **Private AI security for onchain code.** Uncensored or open-weight models in NEAR AI's confidential mode pentest or formally check NEAR/EVM contracts. The output is an attested report, paid via Intents. Code review is already taken by MultiAgency/private-ai, so target contracts and bounties rather than PRs.
3. **Agent provenance or a "black box recorder".** Every agent action in our app carries an attested log that a classifier can scan for policy violations. This works as a feature layer on any agent product.

1. **An "agentic bank run" product for humans.** A user-run agent (local or self-hosted) moves idle stablecoins to the best yield across chains via NEAR Intents, with a confidential balance. 2. **Human-first privacy with selective disclosure.** Private by default, with PnL or proofs shown only when the user chooses (viewing keys / proof-of-payment). This is his "two wolves" in one app, and it overlaps with Illia's copy-trading idea.
3. **Avoid** pitching "agents paying agents" as the core value unless real usage shows it. He has publicly called much of it cope.
